Claude is not the source of truth. The database is.

Determinism

Leave, salary, revenue, P&L, approval state — all computed by SQL. The LLM interprets; it never invents.

Server-side identity

Actor and approver are resolved from the session. An LLM-supplied id is only a lookup key that is re-authorized.

Defense in depth

The permission engine gates each request and RLS re-checks ownership/scope. Bypassing the tool layer still fails.

Business-action MCP

No raw-SQL tool exists — only named actions with risk tiers (READ / write / approval / CRITICAL-blocked).

Idempotent · transactional

Writes carry idempotency keys; multi-step operations run in one transaction. Retries never duplicate.

Immutable audit

Every sensitive action is logged append-only. Denials (PERMISSION_DENIED) are evidence too.
